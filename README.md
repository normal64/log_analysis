# AI-анализатор Журнала Регистрации 1С:Предприятие

Автоматический пайплайн для разбора выгрузок ЖР (`EventLog.xml`), дедупликации ошибок, обезличивания ФИО пользователей и подготовки диагноза со сценариями воспроизведения по исходному коду конфигурации.

## Структура проекта

```text
├── config-dump/              # Выгрузка конфигурации и расширений в XML (.bsl)
│   └── Extensions/           # (Опционально) Выгрузки расширений по подпапкам
│       └── <ИмяРасширения>/
├── log-analysis/             # Парсер и база известных ошибок
│   ├── EventLog.xml          # Выгрузка ЖР (не хранится в Git)
│   ├── known_bugs.json       # Локальная история ошибок (не хранится в Git)
│   ├── parse_log.py          # Парсер, анонимайзер и резолвер путей .bsl
│   └── run_parser.ps1        # Скрипт подготовки и запуска парсера
└── tasks/                    # Сгенерированные задачи и итоговый отчёт
    ├── INDEX.md              # Сводная таблица ошибок
    ├── bug_XX.md             # Детальные карточки задач
    └── DIAGNOSIS_REPORT.md   # Итоговый отчёт ИИ-аналитика
```

## Подготовка новой базы 1С (развёртывание)

1. Склонируйте репозиторий в рабочую папку под конкретную базу 1С.
2. Выгрузите **Журнал регистрации** в формате XML в файл:
   `log-analysis/EventLog.xml`
3. Выгрузите **основную конфигурацию** в файлы (Конфигуратор → *Конфигурация* → *Выгрузить конфигурацию в файлы...*) в папку:
   `config-dump/`
4. *(Если используются расширения)* Выгрузите каждое расширение в отдельную подпапку:
   `config-dump/Extensions/<ИмяРасширения>/`

## Запуск анализа

### Полный цикл через ИИ-агента (Cline в VS Code)

1. Откройте папку проекта в VS Code.
2. Выберите модель с корректной поддержкой вызова инструментов (Claude 3.5/3.7 Sonnet, DeepSeek V3, Qwen 2.5 Coder).
3. Передайте агенту мастер-промпт — он сам запустит парсер, прочитает свежий `tasks/INDEX.md` и сформирует `tasks/DIAGNOSIS_REPORT.md`.

### Только парсинг ЖР (без запуска ИИ)

Выполните в терминале из корня проекта:

```powershell
powershell -ExecutionPolicy Bypass -File "log-analysis/run_parser.ps1"
```

После вывода `PARSER_OK` откройте `tasks/INDEX.md`.
